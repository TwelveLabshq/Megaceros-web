1. Qué datos se recopilan

El formulario de cotización solicita, solo si el usuario decide escribirlos: nombre, producto de interés, medida o calibre, cantidad y zona de entrega.

Este sitio no tiene servidor propio ni base de datos: el formulario arma un mensaje de WhatsApp con esa información y lo abre directamente en la conversación con un asesor de Megaceros. Los datos no quedan guardados en el sitio web.
